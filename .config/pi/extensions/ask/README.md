# ask

エージェントが選択肢を提示して、ダイアログで選ばせる pi 拡張。

文章で「AとBどっちにする?」と聞く代わりに、`↑↓` と `Enter` で選べるUIを出す。

## ツール

### ask — 単一選択

```
────────────────────────────────────────────────────────
 どっちの方式で実装する?

> 1. 正規表現で判定
     依存なし。実装は軽いが誤検知が出る
  2. シェルをパースして判定
     正確だが実装量が増える
  3. 自分で書く

 ↑↓ 選択 • enter 決定 • esc キャンセル
────────────────────────────────────────────────────────
```

最後の「自分で書く」を選ぶとインラインエディタが開いて、任意のテキストを返せる。選択肢に無い答えを渡したいときに使う。

### ask_multi — 複数選択

```
────────────────────────────────────────────────────────
 どのファイルを変更する?

> [x] rules.ts
      危険パターンの判定
  [ ] config.ts
      設定の読み書き
  [x] README.md

 ↑↓ 移動 • space 選択 • a 全切替 • enter 確定 (2件) • esc 中止
────────────────────────────────────────────────────────
```

複数が同時に当てはまる場面で使う。変更するファイルを選ぶ、含める機能を選ぶなど。

## キー操作

| ツール | キー | 動作 |
|---|---|---|
| 共通 | `↑` `↓` | カーソル移動 |
| 共通 | `Enter` | 決定 |
| 共通 | `Esc` | キャンセル |
| ask | `Enter`（自分で書く上） | 自由入力を開く |
| ask | `Esc`（入力中） | 選択肢に戻る |
| ask_multi | `Space` | 選択のトグル |
| ask_multi | `a` | 全選択 / 全解除 |

## 戻り値

エージェントには選択結果がテキストで返る。

| 状況 | 返る内容 |
|---|---|
| 選択した | `User selected: 2. シェルをパースして判定` |
| 自由入力した | `User wrote: 両方いれて設定で切り替える` |
| キャンセルした | `User cancelled without choosing.` |
| 何も選ばず確定（multi） | `User selected nothing.` |
| UIなし（print/json） | `UI not available; ask was skipped.` |

キャンセルはエラーにしない。エージェント側で「選ばれなかった」として扱える。

## 構成

```
ask/
├── index.ts       # 2つのツールを登録
├── ask.ts         # 単一選択 + 自由入力
├── ask-multi.ts   # 複数選択
└── schema.ts      # 共通の選択肢スキーマ
```

## パラメータ

両ツール共通。

```typescript
{
  question: string;
  options: Array<{
    label: string;        // 短く
    description?: string; // 補足はこっちに
  }>;
}
```

## 制限

- TUI モードのみ動作する。`print` (`-p`) と `json` モードではスキップされる
- `executionMode: "sequential"` を指定しているので、他のツールと並行実行されない。ダイアログが複数同時に開くのを防ぐため
- 選択肢が多いとスクロールせず全部並ぶ。10個程度までを想定

## 出典

pi 同梱の [`examples/extensions/question.ts`](https://github.com/earendil-works/pi) をベースに、日本語化と複数選択を追加したもの。
